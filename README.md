# משמרת של אמפתיה

משחק Node.js + WebSocket ל-7 משתתפים ומנהל/ת, מותאם למובייל ו-RTL.

## הפעלה מקומית
1. התקינו Node.js 18+.
2. `npm install`
3. `npm start`
4. פתחו `http://localhost:3000`

## העלאה ל-Render (חינם)
1. העלו את התיקייה ל-GitHub (ריפו חדש).
2. ב-render.com: New → Blueprint → בחרו את הריפו (render.yaml יזוהה אוטומטית).
   או: New → Web Service → Build: `npm install`, Start: `npm start`.
3. קבלו כתובת בסגנון `https://nursing-empathy-game.onrender.com`.

## הערות
- בתוכנית החינמית השרת "נרדם" אחרי 15 דק' ללא שימוש. פתחו את האתר דקה לפני השיעור.
- המשחקים נשמרים בזיכרון — הפעלה מחדש של השרת מוחקת משחק פעיל.
- מנהל/ת: "פתיחת משחק" → שיתוף קישור/קוד → התחלה.
- משתתף שנסגר לו המסך חוזר אוטומטית עם אותו ניקוד.
